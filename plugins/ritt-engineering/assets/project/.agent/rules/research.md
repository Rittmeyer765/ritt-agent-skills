# Research

- Prefer primary sources: official docs for the exact version in the lockfile, source code, specs, release notes. A blog post is a lead, not evidence.
- Cross-check consequential claims against a second independent source.
- Before designing anything new, run the reuse ladder: this repo → organization libraries → maintained ecosystem packages. Record the REUSE / ADAPT / BUILD verdict and rationale in `.agent/CONTEXT.md`.
- Check the latest `.agent/history/YYYY-MM.md` and the active `.agent/tasks/<TASK-ID>.md` first: what was already tried and how it failed is research someone paid for.
- Separate findings by certainty label (`VERIFIED` / `INFERENCE` / `HYPOTHESIS` / `UNVERIFIED`) and cite where each verified fact was observed.
